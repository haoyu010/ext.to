TMDB 匹配

用 TMDB 校验影视信息，补全标题、评分与海报，并可按编号去重。

匹配规则

优先使用详情页提供的 IMDb 编号（tt 开头）通过 TMDB 的 /find 接口定位条目；没有编号时才按标题搜索，且必须标题完全一致。 标题只取发布名的首行，不会读取简介、分享、字幕、体积、标签等正文内容。 繁体发布名会自动折叠成简体再搜，因为 TMDB 按简体登记条目 （長安三萬里 → 长安三万里）； 带季数的名字则用基础名去搜，季数留到推送正文里。

标题解析测试

粘贴一个发布名，查看解析出的标题、年份、类型，以及 TMDB 的匹配结果。

分类过滤

用 TMDB 元数据判断影视的国别与类型，把不需要的分类挡在推送之前。

为什么需要它

种子站的分类太粗：动漫 里同时有国漫、日番和欧美动画， 单靠站点分类无法只留国漫。所以这里按 TMDB 匹配结果的元数据 分类， 再用下面的黑名单排除不要的分类。 分类依赖 TMDB，没有填写 TMDB API Key 时本节规则不会生效； 没有匹配到 TMDB 的条目会被跳过，因为无法确认它属于哪个分类。

分类规则

YAML 格式，一级是 movie / tv， 二级是分类名。可用字段：genre_ids、 original_language、origin_country、 production_countries、release_year。 同一分类内多个字段是「并且」，同一字段多个值用逗号分隔是「或者」， 值前加 ! 表示排除。 条件多的分类优先，条件数相同时按书写顺序；没有任何条件的分类是兜底。

TMDB 黑名单

命中任意一条就会被跳过。默认只保留 国漫 与 国产剧， 其余全部排除；上面的默认规则加上这些黑名单就等于「只推送国漫和国产剧」。

Telegram 推送

配置机器人、目标频道与推送内容格式。

推送目标

向 @BotFather 创建机器人，并把机器人拉进目标频道设为管理员。

推送内容

使用占位符组合消息正文，支持 Telegram 的 HTML 标签（<b>、<i>、<a>、<code>）。 一条正文最多 1024 个字符（带海报时），超出的部分会被 Telegram 拒绝。

种子链接直接写 {torrent_text} 就行， 不要再套 <a>： Telegram 不接受 magnet: 开头的超链接 —— 写成 HTML 锚点会被静默丢掉，写成 entity 会被拒 （Wrong port number specified in the URL）， 所以套上锚点只会让正文看起来像能点，其实点不开。 {torrent_url} 仍是链接的去向（磁力优先，取不到磁力时退回详情页），但它只适合放进 href、不适合直接显示。详情页链接是 {url}。 想要「点一下复制」的话，在下面的「发送选项」里打开复制磁力按钮，但请先看那里的代价说明。

链接印多长由「发送选项」里的只显示 info hash（短链接）决定，默认开启。 短链在正文里拆成两行，magnet:? 下面一行是 xt=urn:btih:…，一共 60 个字符。 关掉则印站点给出的完整链接（实测 400~1200 字符）：它带着发布名和全部 tracker， BT 客户端和网盘离线下载都能用，代价是正文会被这一行占满。

站点把发布名原样写进磁力的 dn 里，而发布名带空格和方括号，这样的 URI 是非法的： 严格解析的下载器读到第一个空格就停，于是「明明看着像链接却用不了」。本程序会把 dn 里的非法字符转义还原成合法 URL（并且逐条实测过能解析出完整发布名）。

{torrent_text} 里的磁力会套上 <code>： Telegram 客户端点一下即可复制，而且能挡住「UIndex.org」这类夹杂在磁力里的字样被自动识别成蓝色链接。 取不到磁力时退回详情页链接，此时是裸链接——实测把 <code> 套在锚点里会连锚点一起失效，而裸 https 链接 Telegram 会自己识别。

Telegram 的图片说明上限是 1024 个字符，且只算看得见的文字：链接的去向（href）不计， <b> 这类标签也不计，&amp; 算 1 个字符而不是 5 个。 而站点给出的磁力实测 331 ~ 1188 字符，未必都放得下（默认的短链接只有 info hash，不占地方），所以渲染时会按顺序让步： 先缩 {tmdb_overview}（320 字起，每 40 字一档，让到 0 就整行去掉，不会只剩一个冒号）； 还不够才从链接尾部丢 tracker，一次丢一整个参数，绝不切在 URL 中间，info hash 永远保留。 正文里的链接若被缩过，就是在整段简介让光之后仍然放不下，此时只能牺牲末尾的 tracker。 {magnet} 也是完整磁力，但它超过上限、带海报时会被 Telegram 拒收，别直接放进正文做显示。 打开「复制磁力按钮」后，按钮另有一份：它最多 256 个字符（实测 257 就被 Telegram 拒），所以固定带上 info hash 和尽量多的 tracker，末尾同样不切在 URL 中间。 {torrent_label} 是旧模板用的文字版（「种子链接」/「详情页」），仍然可用，但转发后只剩那几个字。

TMDB 的条目以文字呈现，用 {tmdb_ref} 会渲染成 tv/287994 这样的类型与编号， 不会把读者引到站外；确实要点开时再用 {tmdb_url}。

带标签的整行（例如 年份：）在该字段为空时会整行省略， 不会只留下一个冒号。

季数与集数取自发布名（{season}、{episode}）， 不是取自 TMDB —— TMDB 的一部剧集条目覆盖全部季，只有发布名才写着是哪一季。 不写季数的发布名、以及电影，这两个字段为空。 推荐用 {season_label}，它渲染成「 第 6 季」（含前导空格）， 无季数时为空，直接接在标题后即可；若标题本身已写出季数则也为空，避免重复。
