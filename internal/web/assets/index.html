TMDB 匹配

用 TMDB 校验影视信息，补全标题、评分与海报，并可按编号去重。

匹配规则

优先使用详情页提供的 IMDb 编号（tt 开头）通过 TMDB 的 /find 接口定位条目；没有编号时才按标题搜索，且必须标题完全一致。 标题只取发布名的首行，不会读取简介、分享、字幕、体积、标签等正文内容。

标题解析测试

粘贴一个发布名，查看解析出的标题、年份、类型，以及 TMDB 的匹配结果。

分类过滤

用 TMDB 元数据判断影视的国别与类型，把不需要的分类挡在推送之前。

为什么需要它

种子站的分类太粗：动漫 里同时有国漫、日番和欧美动画， 单靠站点分类无法只留国漫。所以这里按 TMDB 匹配结果的元数据 分类， 再用下面的黑名单排除不要的分类。 分类依赖 TMDB，没有填写 TMDB API Key 时本节规则不会生效； 没有匹配到 TMDB 的条目会被跳过，因为无法确认它属于哪个分类。

分类规则

YAML 格式，一级是 movie / tv， 二级是分类名。可用字段：genre_ids、 original_language、origin_country、 production_countries、release_year。 同一分类内多个字段是「并且」，同一字段多个值用逗号分隔是「或者」， 值前加 ! 表示排除。 条件多的分类优先，条件数相同时按书写顺序；没有任何条件的分类是兜底。

TMDB 黑名单

命中任意一条就会被跳过。默认只保留 国漫 与 国产剧， 其余全部排除；上面的默认规则加上这些黑名单就等于「只推送国漫和国产剧」。

Telegram 推送

配置机器人、目标频道与推送内容格式。

推送目标

向 @BotFather 创建机器人，并把机器人拉进目标频道设为管理员。

推送内容

使用占位符组合消息正文，支持 Telegram 的 HTML 标签（<b>、<i>、<a>、<code>）。

季数与集数取自发布名（{season}、{episode}）， 不是取自 TMDB —— TMDB 的一部剧集条目覆盖全部季，只有发布名才写着是哪一季。 不写季数的发布名、以及电影，这两个字段为空。
