Cloudflare blocks datacenter traffic, so the forwarder reuses a clearance cookie harvested from a real browser.

How to get these values. Open ext.to in a browser on the same network as this container, pass the "Verifying you are human" check, then copy the cf_clearance cookie value. Cloudflare binds it to both the IP and the User-Agent, so keep the User-Agent identical to that browser's.
